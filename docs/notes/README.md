# Study notes

Revision notes, one file per phase. Each file has:

- **Key ideas**: the concepts, in short form
- **Where it is in the code**: links to the files that use each idea
- **Gotchas**: mistakes that are easy to make
- **Self-test**: questions to answer *before* opening the answer. Trying to recall an answer
  works much better than re-reading it.

|---|---|

| 2 | [Docker and Docker Compose](phase-2-docker.md) |
| 3 | [Caching with Redis](phase-3-redis.md) |

**A good end-of-day routine (about 15 minutes):** answer the self-test questions for today's phase from memory,
then check the answers. For any you got wrong, open the linked code and read it again.
